# 📚 Library Management System

## Overview
A Library Management System built using PostgreSQL and pgAdmin 4 to manage books, members, staff, borrow records, and fines.

## Features
- Database creation
- Table creation
- Data insertion
- CRUD operations
- JOIN queries
- Aggregate functions
- GROUP BY and HAVING
- Window functions
- Views
- Stored procedures
- Triggers

## Technologies Used
- PostgreSQL
- pgAdmin 4
- SQL

## Database Tables
- Books
- Members
- Staff
- Borrow Records
- Fine

## Sample Queries
- Find available books
- List borrowed books with member names
- Find overdue books
- Calculate total fines
- Find most borrowed books
