# 📚 Library Management System

## Overview
A Library Management System built using PostgreSQL and pgAdmin 4 to manage books, members, staff, borrow records, and fines.

## Features
- Database creation
- Table creation
- Data insertion
- CRUD operations
- SQL queries
- JOINs
- Aggregate functions
- GROUP BY and HAVING
- Window functions
- Views

## Database Tables
- Books
- Members
- Staff
- Borrow Records
- Fine

## Technologies Used
- PostgreSQL
- pgAdmin 4
- SQL
